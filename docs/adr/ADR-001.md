# ADR-001 — Standard library only; stable public API

**Decision.** tally has no runtime dependencies outside the Python standard library, and `tally.__all__` is its public API.
**Alternatives.** A CLI framework (rejected: dependency for little gain); a rich-output library (rejected: same).
**Rationale.** The library is vendored into constrained environments.
**Confirmation.** AC-003 (inspection of `pyproject.toml`); API diff in review.
